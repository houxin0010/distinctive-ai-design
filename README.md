# 有个性的 AI 设计

一个中文 Codex skill，用“探索 → 定义 → 交付”建立有辨识度的网页、应用与游戏界面。

包含创意 brief、随机种子探索、独立截图评审、生成媒体使用与减法精修。普通功能修改或局部样式修复不需要启动整套流程。

## 安装

在 Codex 中输入：

```text
使用 skill-installer 安装 https://github.com/houxin0010/distinctive-ai-design 仓库根目录的 skill。
```

也可以将仓库克隆到本地 skill 目录（目标目录必须尚不存在）：

```sh
git clone https://github.com/houxin0010/distinctive-ai-design.git ~/.codex/skills/distinctive-ai-design
```

## 使用

```text
使用 $distinctive-ai-design 改进当前页面：先探索不同视觉方向，再实现最合适的一版，依据实际截图评审并精修。
```

查看 [完整指令](SKILL.md) 和 [评审与媒体参考](references/review-and-media.md)。独立子代理、图像或视频生成均按当前环境能力与任务授权使用；缺少这些能力时说明验证范围。

## 来源与范围

基于 Anshu Chimala 在 Lenny’s Newsletter 的 [How to turn your AI into a world-class designer](https://www.lennysnewsletter.com/p/how-to-turn-your-ai-into-a-world)，于 2026-10-07 阅读公开正文。

仅提炼已读技巧 1–6；技巧 7 只有标题可见，付费正文未纳入。本仓库提供独立编写的执行性改编，不包含原文全文。候选数量、两轮评审预算和运行验证要求是本地适配。
